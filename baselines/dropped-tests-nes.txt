Front-end tests of the old NES app that did not come across unchanged, and what covers
each one now (DESIGN §8, issue #26). One line per old test file, with the old pass count.

This file covers the old app's front end: the drawer, settings, keys, display, audio,
capture and the launch path. The emulator modules that moved into crates/tendy-nes keep
their own tests with the core, so they are not listed here. A line that ends in `none`
is a feature the old app had and TendyEmu does not: the parity rule (SPEC §6) keeps it
with the old app in v0.1, and docs/parity/nes.md carries the gap.
