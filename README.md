# TendyEmu

One emulator for Game Boy, Game Boy Color, Super Game Boy, Game Boy Advance, NES and Super NES.
Open a game file and TendyEmu picks the right system from the file itself.

**Status:** specification stage — no code yet. Read [SPEC.md](SPEC.md); all work is tracked as
[issues](../../issues), grouped by [milestone](../../milestones).
