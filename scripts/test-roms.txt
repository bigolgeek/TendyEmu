# Public test ROMs the pin probes read (DESIGN §5.6, §10).
#
# Nothing here is committed: roms/ is gitignored and scripts/fetch-test-roms.sh writes into
# roms/test/ (or into $TENDY_TEST_ROMS when it is set). Every public URL answered a download
# and its sha256 and byte count are pinned below.
#
# Format: name|url|sha256|bytes|licence
# A row whose sha256 is `-` is local-only: the user supplies that file and the fetch script
# skips it. The probes treat a missing local-only file as a skipped run, not a failure.
#
# Layout the probes expect under TENDY_TEST_ROMS:
#   dmg-acid2.gb                          gb/dmg-acid2, gb/sgb
#   cgb-acid2.gbc                         gb/cgb-acid2
#   cpu_instrs.gb                         gb/cpu_instrs, gb/sgb-sound
#   apu_test/rom_singles/1-len_ctr.nes    nes/cart (the first manifest entry that makes sound)
#   snes-test-roms/<name>.sfc             snes/test-rom (unpacked by the fetch script)
#   sgb-cartridge.bin                     gb/sgb-sound, local only
#   fds-bios.rom, fds-game.fds            nes/fds, local only
