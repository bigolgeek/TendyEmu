# Checkpoint table for tests/game_snapshots.rs -- one real commercial game per line.
# <rom file> TAB <frames>
#
# Frames come from running each ROM headless and stopping at the first frame whose picture had
# been unchanged for 45 frames AND showed more than one colour (cap 2400, then clamped to 1200
# for the games that never stop animating). Emulation is deterministic, so any fixed frame count
# works as a checkpoint; this rule just keeps every hash on a drawn screen instead of on the
# black frame most games show before their title fades in.
#
# Deliberately not listed:
#   mapper 5  (MMC5) is implemented (src/mapper/mmc5.rs); no MMC5 game is in the baseline yet:
#             Castlevania 3 - Dracula's Curse, Bandit Kings of Ancient China, Uncharted Waters,
#             Gemfire, L'Empereur
#   mapper 69 (FME-7), not implemented: Batman - Return of the Joker
#
# The ROMs are copyrighted and are not in the repository. A case whose file is missing is
# reported as skipped, not failed; check the skipped count before trusting a pass.
