- Build: the audio module now imports its device library itself, so the crate-wide placeholder
  import is gone; nothing the player sees changes (#77).
- Settings: the app reads the settings file itself, so a saved volume or rewind length is the one
  in force, without a restart (#77).
- Display: scale, fullscreen, integer scaling, the NES aspect and the status bar are saved in the
  settings file and survive a restart; turning the bar off gives its height back to the picture,
  and an empty window no longer shows a made-up frame rate (#77).
- Settings: scale, fullscreen and integer scaling have one owner on the Video page; the Emulation
  page's THIS GAME rows are labelled `(this game)` and show `(inherit)` until the game overrides
  them (#77).
- Save states: F5 and F7 save and load the slot the State page names, the chosen slot is remembered
  across restarts, and the slot's saved picture is drawn beside the drawer (#77).
- Keys: when a game button is bound to one of the window's keys (P, M, Tab, F1, F2, F3, F5, F7,
  Escape), the button wins and the window's own action is skipped, so one press does one thing
  (#77).
- Rewind: holding Backspace steps the picture back through the saved snapshots while the key is
  down; releasing it resumes play, and the buffer's length follows the `rewind_seconds` setting
  (#77).
